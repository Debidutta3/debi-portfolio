# Debi Dutta Dash — Portfolio Website

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content and page structure
- `style.css` — responsive visual design
- `script.js` — mobile navigation interaction

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

No build tools or package installation are required. An internet connection is needed for the Google Fonts.

## Publish with GitHub Pages (free)
1. Create a new **public** repository on GitHub, for example `debi-portfolio`.
2. Upload `index.html`, `style.css` and `script.js` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your public website address will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/debi-portfolio/`
7. Open that URL in an incognito/private window to confirm it is publicly accessible before adding it to your resume.

Edit the text in `index.html` and the design in `style.css`, then push the changes to GitHub. GitHub Pages republishes the site automatically.
